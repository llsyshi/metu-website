# METU 官网需求文档、页面结构与首页新版布局方案

## 1. 项目定位

METU 官网是广东美途复合材料有限公司的工厂展示型官网，主要用于让国内外客户快速了解公司、产品、制造能力与合作方式，并对工厂产生初步信任和询盘兴趣。

官网第一目标不是立即成交，而是完成三个动作：

- 让客户知道 METU 是中国广东的行李箱 OEM/ODM 工厂。
- 让客户知道 METU 以 PC 行李箱为主，同时支持 PP、铝框、拉链箱和定制箱。
- 让客户相信 METU 虽然是新工厂，但核心团队具备成熟行李箱制造经验和质量控制意识。

## 2. 目标客户

网站同时面向国内和海外客户，但英文应作为主语言，中文作为切换语言。

核心客户包括：

- 海外行李箱品牌方
- 国内外贸易商
- 批发商
- 跨境电商卖家
- 旅行用品公司
- 有贴牌、定制、批量生产需求的采购客户

## 3. 客户需要建立的核心印象

希望客户记住 METU 的关键词：

- PC 行李箱
- OEM/ODM 代工与定制
- 经验丰富的制造团队
- 中国工厂
- 质量控制

这五个关键词应贯穿首页、导航扩展栏、产品区、工厂区、质控区和联系区。

## 4. 内容优先级

当前最重要的信息优先级如下：

1. METU 是什么公司
2. METU 做什么产品
3. METU 是否支持 OEM/ODM
4. METU 为什么可信
5. METU 如何控制质量
6. 客户如何联系 METU

暂时不应过度强调：

- 公司规模很大
- 产能数字很夸张
- 没有依据的认证、客户案例或出口国家数量

因为公司目前是新成立工厂，应该用“经验丰富的制造团队 + 真实工厂展示 + 清晰生产流程 + 品质控制”建立信任。

## 5. 网站风格方向

建议风格为：

> 高端感 + 成熟外贸工厂官网，但更偏工厂可信度。

也就是不要做成普通工厂黄页，也不要做成纯品牌秀场。页面应像一个有审美、有制造能力、适合海外客户浏览的专业行李箱工厂官网。

视觉关键词：

- 高级
- 简洁
- 国际化
- 工厂可信
- 产品质感
- 稳重但不沉闷

推荐色彩：

- 黑色
- 白色
- 深灰
- 金属银
- 少量香槟金作为按钮和强调色

## 9. 首页新版布局方案

### 9.1 首屏

目标：

- 让客户第一眼知道 METU 是行李箱 OEM/ODM 工厂。
- 通过全屏工厂环境和机器设备轮播建立第一印象。
- 提供明确询盘入口。

内容建议：

- 第一行大字：美途：为全球品牌提供拉杆箱解决方案
- 第二行小字：以技术创新驱动制造战略，追求高品质发展
- 文案在每次图片切换后延时出现，第一行先显示，第二行再稍慢一点显示，形成更接近成熟工厂官网的首屏动态效果。

视觉建议：

- 使用全屏轮播图。
- 第一张轮播图使用公司工厂环境图。
- 后续四张轮播图使用工厂机器设备图。
- 设置 5 个圆点作为轮播控制器，支持点击跳转到对应图片。
- 自动轮播和手动点击切换时，两行文字都需要重新延时出现，且第二行比第一行略晚淡入。
- 黑色半透明遮罩增强文字可读性。
- 轮播图片应尽量展示全貌，避免过度裁切；可使用完整图展示 + 背景模糊填充的方式。
- 第一行文字不宜过大，应保持两行文案清晰、克制、专业。
- 图片切换应使用左右方向快速滑动效果，避免卡帧和生硬闪烁。
- 首屏轮播速度不要太快，保持稳重。

### 9.2 信任数据条

在首屏下方放 3-4 个信息点。

由于目前没有真实产能和客户数据，建议先使用结构化能力表达：

- PC 行李箱主推
- OEM/ODM 服务
- 经验丰富的团队
- 质量检查节点

- 生产线数量
- 月产能

## 11. 动效原则

可以参考 Binhao 的动态效果，但不要过度炫技。

建议保留：

- 首屏图片慢速轮播
- 首屏圆点跳转
- 首屏两行文字延时出现
- 首屏图片左右滑动切换
- 导航悬停扩展栏
- 滚动进入动画
- 产品卡片悬停效果
- 数据计数动画
- 流程卡片悬停高亮

避免：

- 太快的动画
- 页面跳动
- 文字被动画遮挡
- 每个区块都使用不同风格的动效

## 12. 第一阶段验收标准

- OEM/ODM 能力明确。

- 中英文切换正常。
- 手机和电脑端都能正常浏览。

## 13. 需求池与版本规划机制

为了避免“想到什么就立刻开发”导致项目混乱，后续所有新想法先进入需求池，再决定是否进入下一个小版本。

### 13.1 为什么需要需求池

当前官网已经包含：

- 首页
- 顶部导航
- 悬停扩展菜单
- 首页全屏轮播
- 产品中心
- PC 行李箱分类页
- MT1007 产品详情页
- 工厂实力
- 质量控制
- 联系区
- 图片素材目录
- 多份维护文档

如果每个想法都立即实现，容易出现：

- 页面结构越来越乱。
- 功能之间互相影响。
- 文档跟不上代码。
- 图片和产品资料命名混乱。
- 某些页面改了，其他页面忘记验证。
- 网站方向从“建立工厂信任”变成“堆功能”。

所以后续建议采用：

```text
想法 -> 需求池 -> 优先级判断 -> 小版本计划 -> 实现 -> 验证 -> 更新文档
```

### 13.2 需求池记录格式

每个新需求先按下面格式记录。

```text
需求名称：
需求来源：
需求类型：
需求描述：
为什么要做：
影响页面：
优先级：
是否进入下个版本：
备注：
```

字段说明：

- 需求名称：一句话说明需求。
- 需求来源：自己想到、参考宾豪、客户反馈、资料补充、技术优化等。
- 需求类型：视觉、内容、产品、工厂、功能、架构、性能、SEO、表单等。
- 需求描述：具体要做什么。
- 为什么要做：它帮助客户理解、信任或询盘的哪个环节。
- 影响页面：首页、产品页、详情页、工厂页、联系区等。
- 优先级：高 / 中 / 低。
- 是否进入下个版本：是 / 否 / 待定。
- 备注：未确定的信息、素材状态、风险。

### 13.4 版本规划规则

每个小版本只解决一个核心问题，避免同时改太多。

#### 需求背景

参考页面：

```text
https://www.binhao.com/about#company
```

当前 METU 已经有首页中的 About 区块，但还没有一个足够完整、正式、具备品牌感的独立公司简介页面。后续用户会补充公司简介、发展信息、团队信息或其他资料，因此本阶段先明确页面结构和交互要求，确认后再进入实现。

本需求的目标不是复制宾豪的文字、图片或品牌内容，而是借鉴其公司简介页的页面组织方式、锚点导航体验、图文展示节奏和滚动动效。

#### 页面目标

- 让海外和国内客户进入 About Us 页面后，快速理解 METU 是一家面向 OEM/ODM 的行李箱制造工厂。
- 解释“新工厂平台”和“经验丰富制造团队”的关系。
- 用真实工厂环境图提升可信度，而不是只依赖文字。
- 为后续补充公司简介、企业文化、发展历程、荣誉资质、工厂能力等内容预留结构。
- 页面视觉要和首页、PC 分类页保持一致，偏高级、简洁、大气、国际化。
- About 页面字体要更正规克制，避免使用过强的杂志感、艺术感标题字体。
- About 页面标题字号不宜过大，整体应比首页首屏和产品页标题更收敛。

#### 参考宾豪的核心体验

可借鉴的功能和结构：

- 页面顶部使用独立 About Banner，形成正式内页入口。
- Banner 下方设置横向栏目导航，点击或滚动到对应内容区。
- 页面内部使用锚点，例如 `#company`，支持从外部链接直接定位到公司简介区。
- 公司简介区采用图文分栏布局：一侧为大图，一侧为标题、段落和重点信息。
- 重要信息通过数字、短语或模块化区块表达，避免整页只有长段落。
- 页面向下滚动时，图片、标题、文字和模块有轻微淡入 / 上移动效。
- 不同内容区之间留足空间，整体有“正式企业官网内页”的秩序感。
- 页面底部需要有完整黑白页脚，包含顶部导航链接、产品链接、公司地址、邮箱、电话、WhatsApp、微信以及社交媒体图标。
- 微信图标悬停时显示二维码占位；Facebook、Instagram、Twitter 等图标点击后先跳转到占位链接，后续替换为真实链接。
